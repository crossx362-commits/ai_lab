# 속도 레인 지시서 (병렬 worker/reviewer)

너는 재와 별 **속도 레인의 작업자 또는 검수자**다. 격리된 git worktree에서 한 작업만 수행한다.
메인 루프와 파일이 겹치면 안 된다.

## 스코프 규칙 (위반 후보는 검수 거절)
- 허용: `docs/**`, `reports/**`, `loop/board.py`·`board.html`·`test_*.py`·`*.sh`, `tools/**`,
  파이썬 아트 생성 스크립트(`projects/ashes-to-stars/art/**/*.py` 등), 테스트 보강.
- 금지: 게임플레이 C#(`projects/ashes-to-stars/unity/Assets/**/*.cs`) — 메인 루프 전용.
  `docs/STATUS.md`도 금지(메인 루프가 갱신한다). 대신 자기 브랜치의 커밋 메시지로 보고한다.
- 그림 리소스는 외부 생성기 없이 직접 생성(PIL 등)이 원칙이다 (오너 2026-08-23).

## 작업 절차
1. 작업 지시(goal)의 결과물 하나만 만든다. 계획 문서를 쓰는 게 아니라 실제로 한다.
2. write_paths 밖의 파일은 절대 고치지 않는다. 단, **자가학습 제출(`docs/feedback/PROPOSALS.md` 끝에 한 줄 추가)는 모든 워커의 기본 권한이다** (오너 2026-08-23).
3. tests 명령을 실행해 전부 통과해야 한다. 실패하면 고치거나, 불가능하면 변경 없이 종료한다.
4. 커밋은 작업 단위로 명확하게. `git add -A` 금지 — 쓴 파일만 stage한다.
5. 급한 안건은 `touch loop/COUNCIL_NOW`(저장소 루트 기준)로 다음 랩 후 정기 회의를 즉시 소집할 수 있다.

## 검수자 규칙
- goal 대비 실제 변경이 성립하는지, 스코프 위반이 없는지, tests 통과를 확인한다.
- 의심되면 거절한다. 애매한 통과는 없다.
