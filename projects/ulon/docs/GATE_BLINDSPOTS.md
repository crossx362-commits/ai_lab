# 게이트 사각지대 표 (2026-09-07)

검수 지시: 「내가 재는 영역 밖에서 누가 그리나/움직이나」 ①과 「내가 세는 대상 밖에 같은 역할을 하는 게
있나」 ②를 게이트마다 묻는다. **찾기만 하고 고치지 않는다** — 수리 지시는 검수가 표를 보고 내린다.

## 방법과 그 한계
게이트 116개(`grep -c "void Assert"`)를 **판정 대상을 어떻게 모으는가**로 읽었다 —
`GameObject.Find(고정 이름)` / `FindObjectsByType<T>`(씬 전수) / 원장 배열 순회 / 이름 접두사 필터 /
소스 파일 문자열. 아래는 **집합의 구멍**만 본 결과다. 임계값이 옳은지, 계측이 정확한지는 이 표의 범위가
아니다. 「없음」은 코드를 읽어 확인한 것이고, 「잠재」는 지금 씬에서는 안 터지지만 규칙상 열려 있는 구멍이다.

## 표

## 두드러진 것 (검수가 순서를 정할 때 쓰라고 뽑음)
1. **소품 4종 게이트가 「던전 실내 + 이름 접두사 + 직계 자식」이라는 한 집합에 전부 매여 있다** —
   집합이 어긋나면 자격·크기·분포·맨바닥이 **동시에** 눈을 감는다. 게다가 자격 게이트에는 「0개면 실패」가 없다.
2. **몹 자격이 마을 NPC를 안 본다** — 맨몸 모델 반려를 받았던 그 결함이 마을에서는 아직 열려 있다.
3. **도달 가능 게이트가 화면을 안 본다** — HUD를 갈아엎는 지금 가장 비싼 사각지대.
4. **차폐·VFX 판정이 야외와 실제 플레이 화면을 안 본다** — 「실내 0.0%」는 실내에 한한 말이다.
