# INBOX

루프가 매 바퀴 맨 먼저 읽는다. 사람이 채운다. 보드에서도 써넣는다.

형식:

- `- [ ] (YYYY-MM-DD HH:MM) 내용`
- 긴급: `- [ ] [긴급] (YYYY-MM-DD HH:MM) 내용`

처리한 항목은 삭제하지 않고 `- [x] · 바퀴#N`으로 바꾼다.
