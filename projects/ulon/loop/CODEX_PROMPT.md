## 알림·정지

대화에 진행 보고·완료 보고를 보내지 않는다. 결과와 막힘·필요한 판단은 공유 보드에만 기록한다.
변화가 없으면 보고를 추가하지 않고 조용히 종료한다.
단, 실행 가능한 카드가 있는데 읽기만 하고 종료하지 않는다. 부모는 코드·에셋 변경 없는 세션을
no_progress로 기록하고 동일 카드 재호출을 유예한다. 새 검증만 수행한 경우도 코드 개발 진척과 구별한다.
유예한 카드는 status 또는 resume_token이 바뀌었을 때 다시 선택한다. 실행 가능한 카드가 없으면
부모가 보드를 로컬로 기다리며 새 CLI를 호출하지 않는다.
사용자가 정지하면 `loop/CODEX_STOP`을 만들고 새 카드를 시작하지 않는다.
추가 결제·유료 API·외부 메시지 발송은 하지 않는다.
