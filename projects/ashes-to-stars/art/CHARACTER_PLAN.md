## ① 앵커 정합성 — ✅ 해결

**문제**: `anchor_characters.png`에 **분홍 몬스터가 섞여 있었다**(구획 5개 중 마지막,
폭 267px로 캐릭터 4종의 136~157px보다 확연히 넓음). 화풍이 달라(도트가 굵고 아웃라인
처리가 다름) 캐릭터 생성 참조에 들어가면 화풍을 오염시킨다.

**조치**: `anchor_characters_clean.png` 생성(830×380, 캐릭터 4종만).
육안 확인 — 4직업의 도트 밀도·아웃라인·명암 단계가 서로 일관하다.

**앵커가 문서의 미해결 충돌 2건을 이미 해결하고 있다** (§0-A "확인 필요"로 남아 있던 것):

| 항목 | 문서 충돌 | 앵커 실제 → **채택** |
|---|---|---|
| 탱커 무기 | 검(시트①) vs 철퇴(시트③) | **십자 문양 방패 + 검** |
| 버퍼 | 악기(시트①) vs 지팡이(시트③) | **녹색 마녀모자 + 류트** (둘의 합성) |

## ② 크레딧 — 예상 9~10시트

- 대상 52장 = 4직업 × 13프레임
- 시트 6셀 상한(`db216381` 실측 확정) → **9~10시트**
- 잔여 크레딧 1106 대비 여유 충분. 중간 고갈로 화풍이 갈릴 위험 없음
- ⚠️ 시트 경계가 **한 직업 안에서 갈리지 않게** 묶는다 — 몹에서 시트별 크롭 때문에
  캔버스가 갈려 걷기가 튄 사고(`c7d66a04`)의 직접 원인이 이것이었다

## ③ 파생 설계 — **기본 4종을 "파츠가 얹히는 몸통"으로 만든다**

§0-B의 절감 구조("1차 전직 11종은 파츠 교체 + 팔레트, 새 실루엣 없음, ~180장")가
성립하려면 **지금 만드는 기본 4종이 그 전제를 만족해야 한다.** 다 만든 뒤에 파츠가
안 얹히면 처음부터 다시다.

### 전직 트리 (기획서 §3 확정)

| 기본 | 1차 전직 | 파생 방식 |
|---|---|---|
| 탱 | 수호기사 · 광전사 | 수호기사=앵커 그대로 / 광전사=방패 제거 + 양손무기 + 분노 오라 |
| 딜 | 검사 · 궁수 · 마법사 · 소환사 | **무기만 교체**(검/활/지팡이/소환진) |
| 힐 | 사제 · 드루이드 | 사제=앵커 그대로 / 드루이드=후드→뿔·자연 장식, 팔레트 백금→갈녹 |
| 버퍼 | 음유시인 · 주술사 · 정령사 | 음유시인=앵커 그대로(류트) / 주술사=토템 / 정령사=정령 오브 |

### 그래서 지키는 제작 규칙 4가지

1. **손 위치를 프레임 간 고정.** 무기가 바뀌어도 쥐는 지점이 같아야 오버레이가 성립한다.
   딜러가 검→활→지팡이로 갈리므로 특히 중요하다.
2. **머리 장식을 실루엣 상단에 분리 가능하게.** 후드·모자·투구가 교체 대상이다.
3. **망토·장비를 몸통과 색으로 구분.** 팔레트 스왑(종족 4종, 추가 0장)이 여기 걸린다.
4. **캔버스·발 위치를 13프레임 전부 통일.** 현재 임시본은 4직업 전부 416×297로
   일관하다 — 이 성질을 잃지 마라. 몹은 이걸 어겨서 걷기가 튀었다.

### 2차 전직 = 오버레이로 처리 (신규 몸통 0)

기획서가 "분기 없이 같은 직업의 각성(초필살기·**외형 강화**)"으로 확정했으므로,
오라·이펙트·장식 오버레이로 낸다. 새 실루엣을 그리지 않는다.
