# 재와 별 — 그래픽 리소스 파이프라인

## 결론 (2026-08-14 실측)

기존 에셋을 실제로 측정해보니 **캐릭터가 좋고 프랍이 나빴다** — 처음 세운 가설과 정반대다.

| 에셋 | 크기 | 색 수 | 판정 |
|---|---|---|---|
| `sprites/*/*.png` (캐릭터, 오너 AI 시트 분할) | 416×297 | 9,126 | ✅ 이미 최종 품질. 9천 색은 안티에일리어싱 탓이지 화풍 문제가 아니다 |
| `props/*.png` (블렌더 절차생성) | 96×96 | 8 | ❌ 회색 원통·삼각뿔 수준. 캐릭터와 같은 화면에 못 놓는다 |

→ **캐릭터는 손대지 않는다. 프랍·배경·아이콘을 캐릭터 수준으로 끌어올린다.**
캐릭터를 픽셀화해 프랍에 맞추려던 시도는 실측으로 폐기했다(`pixelize.py` 상단 경고 참조).

## 방식

프롬프트로 "픽셀아트 스타일"이라 말해봐야 호출마다 다른 그림이 나온다. 그래서 두 겹으로 강제한다.

1. **스타일 앵커** — `anchor_characters.png`(오너 캐릭터 5종을 이어붙인 것)를 매 생성 호출에 참조 이미지로 첨부한다. 이미 품질이 확정된 화풍이라 새로 그릴 앵커가 필요 없다.
2. **공용 후처리** — 생성기가 무엇이든 산출물 전부를 `pixelize.py` 하나로 통과시켜 해상도·팔레트·외곽선을 물리적으로 통일한다.

즉 **AI는 내용만 만들고, 스타일은 코드가 강제한다.**

## 파일

| 파일 | 역할 |
|---|---|
| `aigen.py` | Gemini 이미지 생성 + 마젠타 크로마키 → 투명 PNG |
| `pixelize.py` | 공용 스타일 정규화기 (트림 → 축소 → 알파 이진화 → 팔레트 양자화 → 1px 외곽선) |
| `spec_props.json` | 프랍 명세. 여기에 항목을 늘리면 물량이 늘어난다 |
| `anchor_characters.png` | 스타일 앵커 |
| `palette.json` | 공용 팔레트 40색 |

## 🔴 현재 막힌 것 — 오너 조치 필요

생성 경로 4개를 전부 실호출로 확인했다. **전부 결제·인증 게이트에 막혀 있어 지금은 한 장도 못 뽑는다.**

| 경로 | 상태 |
|---|---|
| Gemini `gemini-3-pro-image` / `3.1-flash-image` | 429 — 무료 티어 이미지 생성 한도가 **0**. 결제 등록 필요 |
| OpenAI `gpt-image-1` | 429 `credit_balance_exhausted` — 크레딧 소진 |
| Higgsfield CLI (설치됨) | `Not authenticated` — `hf auth login` 필요(브라우저 OAuth라 에이전트가 대신 못 함) |
| Unity MCP `generate_image` | fal / openrouter 둘 다 `configured: false` |

**가장 싼 해제 순서**

1. Higgsfield 계정이 있으면 — 카드 없이 한 줄로 끝난다. 게임 스프라이트시트·타일러블 텍스처 전용 모델도 있다.
   ```bash
   hf auth login
   ```
2. 없으면 Gemini에 결제 등록 (https://aistudio.google.com/apikey → Billing). 등록만 되면 아래가 바로 돈다.
   ```bash
   python3 art/aigen.py --spec art/spec_props.json --out-dir art/out_ai --height 96
   ```

해제되면 프랍 6종 스파이크 → 눈으로 확인 → 통과 시 바이옴 전체로 물량 확대 순으로 진행한다.
