SpacePulse

내 PC에서 무엇이 공간과 메모리를 차지하는지 한눈에 보고, 필요 없는 항목은 그 자리에서 정리할 수 있는 Windows 관리 도구입니다.

💡 왜 만들었나요

저장공간이 부족할 때 Windows 설정과 작업 관리자, 파일 탐색기를 계속 오가야 하는 게 불편했습니다. 폴더 이름만 보고는 지워도 되는지 알기 어렵고, 메모리를 많이 쓰는 프로세스도 이름만으로는 정체를 알기 힘들었습니다. 그래서 크기뿐 아니라 무엇이고, 건드리면 어떤 일이 생기는지 함께 보여주는 프로그램을 만들었습니다.

✨ 주요 기능

🗂️ 저장공간 분석
PC의 드라이브와 폴더를 검색해 용량이 큰 항목부터 타일로 표시하고, 폴더 안쪽까지 단계별로 탐색
🧠 메모리 확인
실행 중인 프로세스의 메모리 사용량과 역할을 보여주고, Windows 핵심 프로세스는 종료하지 못하도록 보호
📦 프로그램 제거
설치된 프로그램의 버전·제작사·위치를 확인하고 공식 제거 프로그램 실행과 남은 폴더 정리를 연결
🧹 Windows 정리
임시 파일·DirectX 셰이더 캐시·충돌 덤프·오류 보고서·휴지통의 예상 정리 용량을 미리 확인
🚦 위험도 안내
초록·노랑·빨강으로 정리 가능 여부를 구분하고, 선택한 항목이 무슨 역할인지와 주의사항을 설명
🛡️ 확인 후 실행
프로세스 종료·파일 정리·프로그램 제거처럼 되돌리기 어려운 동작은 실행 전에 대상과 영향을 다시 확인

🛠️ 기술

PythonTkinterPowerShell Windows API비동기 드라이브 스캔PyInstaller

⚠️ 사용 전 확인

Windows 10·11용 프로그램입니다. 설치 없이 압축을 풀고 SpacePulse.exe를 실행하면 됩니다.
프로세스 종료와 파일 정리 기능은 저장하지 않은 작업이나 필요한 파일에 영향을 줄 수 있습니다. 설명과 확인창을 읽고, 용도를 아는 항목만 정리해 주세요.
