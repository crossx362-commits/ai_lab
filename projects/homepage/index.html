백수장인

게임 캐릭터를 움직이게 하는 일을 18년 했습니다. 캐주얼 TPS로 시작해 MMORPG, 모바일, 언리얼까지 20여 개 프로젝트를 거쳤어요.

요즘은 퇴근하고 나면 AI를 붙들고 이것저것 만듭니다. 반려동물 앱, 방화벽 프로그램, 장부 웹앱, 스팀에 낼 게임 — 만들다 보니 여기까지 왔습니다. 노는 것처럼 보이는데 뭔가 계속 나온다고 해서 백수장인입니다.

본업 이야기

캐릭터가 화면에서 어떻게 움직여야 납득이 가는지, 그걸 18년 동안 고민했습니다. 리깅해서 뼈를 심고, 키를 잡고, 컷씬을 연출하고, 엔진에 올려 검수하는 것까지 — 한 프로젝트 안에서 이 과정을 여러 번 돌았어요.

키 애니메이션리깅·컨트롤러 시네마틱·컷씬모션캡쳐 후보정 클로스·피직스리타게팅·최적화 Unity · Unreal 적용·검수외주 검수

퇴근하고 나서 하는 것

처음엔 애니메이션 레퍼런스를 뽑으려고 AI를 켰는데, 어느새 앱을 만들고 있었습니다. 아래는 전부 실제로 굴려본 것들이에요.

  • 웹·프로그램 — 반려동물 앱, Windows 방화벽 앱, 장부 웹앱, 스팀 게임. 기획부터 배포까지 혼자.
  • 자동화 — 코드를 고치고 검수하고 배포하는 AI 에이전트 9대를 상시 돌리는 중입니다.
  • 리소스 생성 — 캐릭터 시트, 모션 시트, 환경 컨셉, 음악까지 생성형 AI로 뽑아 씁니다.
  • 문서·검증 — 기획서와 제작 가이드를 쓰고, QA 순찰·E2E 테스트를 자동 루프로 돌립니다.
