GeoGuard

선택한 국가의 IP 통신을 Windows 방화벽 커널 레벨에서 차단해 주는 트레이 상주 보안 프로그램입니다. 누구나 무료로 받아서 쓸 수 있어요.

💡 왜 만들었나요

PC를 쓰다 보면 해외 특정 지역에서 들어오는 접속 시도나, 내 프로그램이 몰래 해외로 나가는 연결이 신경 쓰일 때가 있죠. 그런데 이걸 막아주는 도구는 대부분 유료이거나 설정이 복잡했습니다. 그래서 국가만 고르면 끝나는 간단한 차단 도구를 직접 만들었어요.

⚙️ 어떻게 동작하나요

🚫 커널 레벨 차단
국가별 IP 대역(RIR 위임 데이터)을 Windows 방화벽(WFP)에 등록 — 프로그램을 꺼도 차단은 유지
🔔 실시간 알림
차단이 발생하면 어떤 프로세스가 어디로 접속하려 했는지 풍선 알림으로 표시
📊 연결 모니터
현재 TCP 연결 목록 + 국가·조직(ISP) 표시, 필터·정렬, 프로세스 강제 종료
📜 차단 이력
차단된 시도를 시간순으로 확인
🔁 fail-closed 설계
IP 목록을 못 받아 차단이 빈 상태가 되면 경고 아이콘 + 지수 백오프 자동 재시도
🪶 가볍게
설치 없는 단일 실행 파일(73KB) — .NET Framework 내장 컴파일러로 빌드해 SDK도 불필요

📟 실제 동작 기록

트레이에 상주하는 프로그램이라 보여드릴 화면이 크지 않아, 실제 실행 로그를 그대로 옮깁니다. 기동할 때 IP 대역을 받아 방화벽에 규칙으로 올리고, 그 뒤로는 차단이 생길 때마다 어떤 프로세스가 어디로 나가려 했는지를 기록합니다.
