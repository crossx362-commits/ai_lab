파이썬 실행 관리자

지금 내 PC에서 돌아가는 파이썬 프로세스가 뭔지, 왜 실행 중인지 몰라서 함부로 못 끄는 상황을 위해 만들었습니다. 설치 없이 실행 파일 하나로 바로 씁니다.

💡 왜 만들었나요

여러 파이썬 스크립트·봇·서버를 동시에 돌리다 보면 작업 관리자에는 python.exe만 잔뜩 떠서 어떤 게 뭘 하는 프로세스인지 구분이 안 됩니다. 잘못 끄면 돌아가던 작업이 날아갈 수도 있고요. 그래서 이름이 아니라 역할로 보여주는 파이썬 전용 프로세스 관리자를 만들었습니다.

✨ 주요 기능

🔎 자동 탐지 & 백그라운드 스캔
python.exe/pythonw.exe/py.exe 및 uvicorn·streamlit·jupyter·celery·pytest 등 프레임워크까지 스캔, 화면 멈춤 없이 비동기로
🧠 역할 자동 분석
소스 코드 상단 독스트링·import문을 읽기 전용으로 분석해 AI 에이전트/서버/봇/트레이딩/모니터링 중 어떤 역할인지 자연어로 설명
🔒 안전 종료
현재 프로그램 자기 자신과 Windows 핵심 시스템 프로세스는 종료 보호, 정상 종료 실패 시에만 강제 종료 옵션 노출
🕶️ 민감정보 마스킹
API_KEY·TOKEN·SECRET·PASSWORD 등이 보이면 자동으로 ******** 처리
🌳 다크 모드 & 트리 뷰
고대비 시스템 모니터 스타일, 목록/트리(부모-자식 관계) 전환 지원
🧰 편의 기능
소스 폴더 열기·소스 보기(읽기 전용)·실행 명령 클립보드 복사·종료 로그 자동 기록
