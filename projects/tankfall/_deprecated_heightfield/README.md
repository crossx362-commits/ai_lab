# 폐기 (2026-09-15, 오너 지시 "힉스필드 쓰지말어 코드로 그려")

Heightfield(높이 격자) 방식. SDF 볼륨(../SdfVolume.cs)으로 대체됨.

폐기 사유: 컬럼당 높이가 하나라 오버행·동굴·발밑 관통이 구조적으로 불가능.
기획서 §21(구형 폭발)·§28(발밑 도려내 떨어뜨리기)이 성립하지 않았다.

⚠️ 여기서 얻은 교훈은 SDF에서도 유효하다 — 명세 §7 참조:
  - 구 불리언 크레이터 벽은 72° (SDF에서는 더 가파른 수직)
  - 탱크 등반 한계 42°와 충돌 → 갇힘 방지 규칙이 반드시 필요하다
  - 참조 구현 ↔ 포팅 수치 대조 + 네거티브 컨트롤 하네스 패턴은 계속 쓴다
