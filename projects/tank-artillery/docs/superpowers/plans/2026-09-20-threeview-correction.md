# 오너 재지시: 실제 3면 원화 기준으로 다시 수정

이전 12종 결과는 3면도 형상 일치 작업 완료가 아니다. 정면 bbox 보정만으로 완료 보고했던 문제를 바로잡는다. 승인된 Laser 파일은 보존한다.

1. 수정 시작 전에 기종별 Blender scene에 정면·측면·상면 원본 crop을 실제 직교축 reference empty로 배치한다. 3개 모두 활성화하고 해당 축에서만 보이도록 한다. 원본은 변경하지 않는다.
2. 기존 모델/36개 비교 렌더를 기준선으로 보존한다.
3. A/B/C의 12종에 대해 담당자가 원본 3면도를 실제 열어 보고 부품별 형상·길이·폭·깊이·연결 오류를 기록한다. 레이저처럼 실제 윤곽과 단면을 수정한다. 단순 정면 bbox 재보정은 이번 작업으로 인정하지 않는다.
4. 수정 모델 정면/측면/상면을 고정된 카메라로 렌더링하고 각 원화와 겹쳐 직접 확인한다. 한 방향 수정 때문에 다른 방향이 망가지면 다시 수정한다.
5. 각 기종의 세 방향 evidence가 생성되고 실제 검토되기 전에는 주 프로젝트 모델·앱을 덮어쓰지 않는다. 검사 PASS는 미술 일치와 구분한다.
6. UV 데칼은 최종 형상에 다시 부착한다. 게임 판정 TankShape/fireZ/반지름 불변. 검증 후 headless Unity bake/rig/팀색/캡처/build/runtime, 주 프로젝트에 적용한다.

작업 분리: subagent-driven-development 절차로 독립 A/B/C 형상 모듈에 담당을 둔다. root는 실제 3축 workbench, 공통 파이프라인, 렌더/개별 검토, 통합/게임 검증을 담당한다. 기존 원본과 승인 Laser에 쓰지 않는다. 3면 원화끼리 맞지 않는 지점은 근거를 남기며 100% 일치로 허위 판정하지 않는다.
