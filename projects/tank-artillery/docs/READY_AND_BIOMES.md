# 선택·배치 준비와 맵 테마

2026-09-19 사용자 요청 반영.

## 게임 흐름

- 일반 전투 탱크 선택: 45초. 방향키/WASD로 커서 이동, Space 선택/해제, Enter 확정. 시간 종료 시 현재 선택을 보존하고 빈 슬롯을 기종 순서대로 채워 전투 설정으로 이동한다. 설정에서 선택으로 돌아가면 45초를 다시 준다.
- 설정 후 인게임: 30초 배치 준비. W/S 이동, A/D 회전, Tab으로 살아 있는 아군 순환. 준비 중 포격·아이템·전투 시계·상대 AI 턴은 진행하지 않는다.
- 각 탱크는 시작 위치에서 수평 반경 25m 안에서 위치를 잡는다. 준비 중 이동 게이지를 보충하고 전투 시작 시 전원 정상 게이지로 복원한다.
- Enter로 일찍 준비 완료하거나 30초 만료 시 첫 번째 탱크의 이동 단계부터 시작한다. Esc 일시정지 중 준비 시간도 멈춘다.
- 연습장과 기존 자동 포격 검사들은 준비 대기를 생략한다. 일반 전투에서는 준비 단계가 적용된다.

## 미사일

- 무작위 비행의 미사일 프로파일은 큰 반복 나선에서 작은 한 번의 방향 보정으로 변경. 기존 변위 계수의 22%, 수직 보정은 그보다 작다.
- 미사일 축 회전은 초당 70도에서 14도로 감소. 초기 자세 연출은 실제 진행 방향을 80% 반영하여 노즈만 과장되게 들리는 느낌을 줄였다.
- 배기 흔적은 더 굵고 오래 남으며 위로 떠오르는 속도를 줄였다. 사거리·피해 수치를 바꾸거나 화면에서 별도 위치 물리를 돌리지 않는다.

## 검사

`bash tools/verify.sh pregame`: 타이머 시작·일시정지·초과시간·일회성 만료·재시작·잘못된 시간, 미사일 최대 흔들림 검사. 빈 구현에서 실패한 뒤 구현 후 통과.

`-pregameselftest`: 실제 선택 자동편성 → StartBattle → 배치 이동·Tab에 연결된 전환 함수·일시정지 → 만료 → 전투 상태와 게이지 복원 확인. 선택/준비/전투 화면 캡처.

`WorldArtVerify`: 12개 맵/날씨 조합에서 바닥·장식 존재, 메시 삼각형 수, 장식 충돌체 없음, 배경 메시가 전장을 덮지 않음을 확인한다.

밸런스 승률을 재측정한 작업은 아니다.

최종 확인: Mac 빌드 오류 0, pregame/ball/compile 통과, 맵 자원 12개 조합 검사 통과. 실제 배치 흐름 검사와 1280×720 UI 22/22 캡처 통과. 6개 맵 자동 포격 완료(5개 13/13, Badlands 11/11: 해당 실행에서 생성한 비행·착탄 캡처 수). 각 맵 장식 배치 수 10/25/13/11/17/11개를 실행 로그로 확인했다. 마지막 타일 경계 미분 수정 후 Mac 재빌드 및 Terrace 포격 13/13을 다시 확인했다. 다른 맵의 실행은 마지막 텍스처 미분 수정 전 결과다. 로그는 `output/ready-biomes/verification/`.
