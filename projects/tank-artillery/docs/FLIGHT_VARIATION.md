# 발사체 비행 변화

2026-09-19 요청: 모든 탄을 포물선으로 날리지 말고 무작위성을 적용.

## 조사와 적용 범위

- NASA [Basic Rocket Motion](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/basic-rocket-motion/): 추진·중력·항력·양력의 크기와 방향이 운동에 영향을 준다.
- NASA [Rocket Aerodynamics](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/rocket-aerodynamics/): 항력은 운동 반대 방향, 양력은 운동에 수직이며 로켓의 방향 제어에 이용된다.

이 자료는 일정 중력만 사용하는 포물선 외에 방향 제어를 설계하는 근거다. 아래 진폭·주기·기종 배정은 현실 수치나 포트리스2 복원이 아니라 이 게임용 창작이다. 나선이 현실 로켓의 일반적인 비행이라는 뜻은 아니다.

## 기종별 제어

| 기종 | 초기 비행 |
|---|---|
| 미사일·멀티미사일·슈퍼탱크 | 좌우·상하 나선 |
| 포세이돈·세크윈드 | 좌우 물결 |
| 캐터펄트·마인랜더·이온어태커 | 위로 솟구친 뒤 원래 탄도로 복귀 |
| 캐롯·듀크 | 한쪽으로 크게 휘었다 복귀 |
| 캐논·크로스보우·레이저 | 기존 탄도/추진 유지, 비교 기준 |

발사 속도 벡터의 정수 해시로 회전 방향·진폭·주기를 선택한다. 각도·파워·분산이 바뀌면 모양도 달라지고 같은 발사는 그대로 재현된다. 매 프레임 주사위를 굴리거나 같은 입력에서 매번 다른 결과를 내는 방식은 아니다.

변형은 최대 2초, 저각에서는 더 짧게 적용한다. 양 끝의 변위와 기울기는 0이다. 포구와 후반 탄도를 유지하면서 초기 비행을 다양화한다. 속도도 같은 변위 함수의 미분을 반영한다. 지형·탱크 충돌은 변형된 실제 위치로 검사한다. 중간 장애물이나 높은 표적에는 기존 탄도와 다른 결과가 날 수 있다. 기존 조준 역산은 후반 기본 탄도를 풀며, 새 중간 곡선을 역산하는 전역 해법은 아니다.

회오리 통과 시 초기 제어를 재시작하지 않는다. 유도탄은 기존 표적 탐색·유도 단계로 연결한다. 일반탄과 특수탄의 기본 제어는 같아 기존 탄종 선택 가정을 보존한다.

## 검증

`bash tools/verify.sh ball`: 기존 조준/추진 검사에 발사 평면 양쪽으로 흔들리는 실제 위치, 재현성, 발사 조건 변화, 끝점, 위치-속도 일치를 추가했다. 초기 코드는 물결 검사에 실패했고 적용 후 통과했다. 초기 2초 고정 방식은 근거리 오차 검사에서 실패하여 저각 제어 시간을 줄였다.

밸런스 승률 재측정은 수행하지 않았다.

실행 확인: Mac 빌드 오류 0, `verify.sh ball` 및 `compile` 통과. TwinHills에서 MultiMissile/IonAttacker/Poseidon/SecWind 특수탄 자동 포격 완료, 비행·착탄 포함 캡처 13/13 검사 통과. 로그: `output/flight-variation/verification/`. 이는 전체 기종·맵 밸런스 검증을 뜻하지 않는다.
