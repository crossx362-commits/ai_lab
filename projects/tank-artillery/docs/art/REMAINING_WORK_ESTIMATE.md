## 판단 전제

- 현재 비교 카메라는 정본의 기종별 투영/조준각과 완전히 일치하지 않는다. 좌우에만 있는 문양이 안 보이는 것을 곧바로 모델 누락으로 판정하지 않는다. 반대편 시점도 확인한다.
- 공통으로 눈이 평평하고 눈꺼풀과 얼굴 면의 연결이 약하다. 궤도·차대의 단순한 공통 형태가 원화의 종별 차이를 충분히 재현하지 못한다.
- 13종 파일 존재 및 생성 가능은 확인됐지만 원화 형상 합격은 아니다. 당근의 회전·눈동자만 추가 검증됐으며 다른 기종까지 완료됐다는 의미가 아니다.

## 기종별 남은 작업

기종별 추정에는 형상 수정, 해당 종의 회전·눈·팀색 작업, 2~3회 렌더 대조를 포함한다. 반복 횟수가 늘면 범위를 넘을 수 있다.

| Cannon | 뚜껑이 떠 보이는 형태, 눈/눈썹과 구체의 연결, 차대·바퀴 비례 수정. 해골 문양은 반대쪽 시점 확인 후 위치/크기 수정 | 2~4시간 |

## 공통 작업과 일정 범위

| 작업 | 예상 |
|---|---:|
| 기종별 형상·회전·눈·팀색 및 반복 렌더 | 38~70시간 |
| 정본과 카메라/배열/크기 정렬, 실제 전투 비교판, 모델 전용 전환·기존 코드 대조군 보관 및 생성 경로 삭제, 8대+폭발 전후 성능 측정, 빌드/회귀 | 12~20시간 |
| 추가 수정 여유 | 약10시간 |
| **합계** | **집중 작업 약60~100시간** |

하루8시간 작업량으로 환산하면 약8~13일이다. 이는 연속 작업을 보장하는 달력 약속이 아니다. 예약 작업은 꺼져 있으며 작업하지 않는 시간은 제외한다.

첫 중간 목표는 12~20시간 범위에서 큰 차이 6종의 실루엣 1차 수정과 같은 카메라 비교다. 최종 완료 목표와 구분한다. 우선 Laser와 MultiMissile을 완결된 한 사이클로 수정하고 실제 투입시간/남은 차이를 기록하면 전체 추정을 다시 좁힐 수 있다.

**불확실성:** 기존 반복 작업이 정본 일치를 충분히 줄이지 못했으므로 이 추정의 신뢰도는 낮다. 60~100시간 후 자동으로 100% 일치한다고 보장하지 않는다. 원화에 없는 후면 해석 및 서로 모순되는 3면도는 정본 우선으로 정리해야 한다. 최종 합격은 오너가 지정한 두 비교판과 판정 불변·팀색·성능 검증을 모두 만족해야 한다.
