# 레이저 정면 원화 기준 위치 정렬

## 확정 기준

2026-09-20 오너가 “ㅇㅇ 그리해”로 정면 원화 우선을 승인했다. 정본은 `art/concepts/orthographic-v1/Laser.png`의 FRONT 그림이다. 원화는 변경하지 않았다. 정면과 배치가 다른 SIDE/TOP 그림은 입체 구조 참고용으로 남긴다. 서로 다른 간격을 감추려고 비교 이미지를 늘이거나 카메라를 결과에 맞춰 움직이지 않는다.

## 반영한 모델

`laser_front_shapes.json`에 머리 덮개, 눈 주위, 턱, 어깨, 날개 세 개, 발사부의 원화 좌표를 기록했다. `laser_front_form.py`는 그 윤곽에 실제 깊이와 두께를 부여해 편집 가능한 메시를 만든다. 그림을 메시 표면에 붙여 모델링을 대신하지 않았다. 좌우 눈은 원화의 비대칭까지 각각 추출했다. 추진구 중심·폭·높이도 정면 기준으로 보정했다.

후방 배기구의 덮개 관통과 턱 겹침을 수정했다. 머리 장식과 판재 끝의 면 방향 오류는 중복 정점 정리·퇴화 면 제거·노멀 경계 분리로 고쳤고, Unity 검사를 완화하지 않았다. 장식 선도 메시로 변환해 FBX와 게임 자산에 포함했다.

## 고정 정면 렌더 측정

카메라는 555×360 원화 크롭과 같은 고정 등록 좌표다. 모델 크기에 맞춘 재정렬은 없다.

| 부위 | 위치 차이 |
|---|---:|
| 왼눈 / 오른눈 중심 | 0.121 / 0.161 px |
| 왼쪽 / 오른쪽 추진구 발광부 중심 | 0.425 / 0.351 px |
| 왼쪽 / 중앙 / 오른쪽 날개 끝 | 2.683 / 1.601 / 1.104 px |

눈과 추진구는 원화의 청록색 픽셀 영역을 비교했다. 날개 끝은 원화를 수동으로 따라 표시한 윤곽이 기준이다. 이 값들은 부품의 정면 위치 측정이며, 모델 전체의 유사도나 모든 문양·재질이 100% 같다는 판정이 아니다.

증거: `output/laser-front-authority/position-evidence.json`, `front-review.png`. 전자는 원화·Blender 모델·런타임 JSON의 SHA-256도 기록한다.

## Blender와 Unity 전달 상태

- `art/blender/laser_reference_workbench.blend`: 최신 편집 가능한 모델, 정면 원화 45% 겹침 활성. SIDE/TOP 원화 평면은 보관하되 숨겨 잘못된 배치 목표로 사용하지 않는다.
- `art/blender/characters/Laser.blend`, 공용 로스터, FBX, 런타임 JSON, Unity 영속 메시/프리팹을 갱신했다.
- `unity-delivery-bake.log`: 13종 탱크와 26종 발사체 자산 검사 통과.
- `unity-aim-capture.log`: 117개 조준 포즈와 13종 시각 포구 교란 독립성 검사 통과, 레이저 5개 게임 카메라 프레임 촬영.
- `build-mac.log`: Mac 빌드 성공, 402 MB, 에러 0.
- `runtime-roster.log`: 빌드된 게임에서 13종 로드 검사 통과. 이는 13종 전체의 미술 합격 판정은 아니다.
- `unity/Build/Tankfall.app`에 전달했다. 실행 파일과 `resources.assets`의 복사 전후 해시 일치 확인.

위 로그와 복사 확인 JSON은 `output/laser-front-authority/`에 있다. 포구·히트박스·반지름의 TankShape 기준은 바꾸지 않았다. 레이저 39,348 삼각형이며, 8대+폭발 실시간 성능 검사는 이번 위치 정렬의 완료 항목에 포함하지 않았다.
