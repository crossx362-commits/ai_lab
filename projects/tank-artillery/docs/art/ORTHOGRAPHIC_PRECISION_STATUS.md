# 원화 일치 작업 상태 — 2026-09-20

사용자 요구는 원화와 100% 같은 형태다. 현재 결과는 미달이며, 이 문서는 완료 보고가 아니다.
사용자는 헤드리스 작업 및 조건 충족 전 중간 보고 중지를 요청했다. 이후 Blender와 Unity 모두 별도 배치 프로세스로 작업했고 사용자 편집기/브라우저를 조작하지 않았다.

## 반영한 수정

- Catapult: 세로 원통 몸통을 가로로 길고 앞면이 둥근 사각형인 나무 몸통으로 재구성. 서로 다른 앞뒤 바퀴 크기, 경사진 눈썹, 깊은 가죽 돌주머니, 꼬인 로프와 매듭, 돌, 투석 팔과 베어링 재구성.
- CrossBow: 눈 크기, 겹친 나뭇잎 면 방향, 전면 장식 수정. 활을 뒤쪽으로 옮기고 원화에 없는 길게 돌출된 정지 상태 화살 제거.
- Cannon: 몸통/눈/뚜껑이 포신 조준각에 같이 기울던 구조 분리. 해골 문양을 구체 표면에 붙이고 포구 원점 수정.
- Missile: 눈을 기체 앞쪽으로 이동하고 좌우 면 방향에 맞춤. 꼬리 날개를 실제 좌우로 펼쳐지는 면으로 교체.
- Duke/Poseidon: 눈의 크기와 위치를 몸체 표면에 맞춰 조정.
- Laser: 포신 판을 아래로 기울어지는 실제 입체 면으로 교체하고 발사점을 끝에 맞춤.
- SuperTank: 왕관 뾰족 장식 높이 수정.
- SecWind: 날개의 뒤쪽 길이, 머리·부리 높이와 비율, 터빈·볏 배치 재구성.
- 이전에 수정했지만 재생성되지 않았던 13종 그룹 회전/크기 및 형태 변경을 모두 다시 내보냄.

## 확인한 실행 결과

- Blender 원본 .blend → JSON: 13종의 위치/회전/크기 대조 통과. 비단위 변환 그룹 27개. 회전·크기를 고의로 누락시킨 음성 대조에서 오류 검출.
- Unity 별도 배치 프로젝트: 13 FBX/탱크 프리팹, 26 발사체 프리팹 검증 통과. 정점/그룹 위치·회전·크기 및 조준 원점 검사 통과.
- 39개 모델/발사체, 889236개 삼각형 검사 통과.
- Mac 배치 빌드 성공, 오류 0. 주 프로젝트 네이티브 에셋과 Build/Tankfall.app에 반영.
- 실제 빌드의 -batchmode -rosterselftest: 13종 로스터 검사 종료 성공. 이는 형태 일치나 화면 품질 판정이 아니다.
- 정면·측면·평면 실제 Blender 렌더 39장과 13개 겹침 이미지 생성. 모든 모델 렌더의 투명 배경 확인.
- tools/verify.sh compile 통과. 기존 경고 2개(폐기 예정 API 및 미할당 필드)는 남음.

## 아직 충족하지 못한 기준

- 전체 원화와 100% 형태 일치: 미달. 비교 화면의 자동 외곽 정렬은 일치율 측정이 아니다.
- 3면도 자체도 같은 형상의 일관된 직교 투영으로 생성되지 않았다. 예: IonAttacker 보조 눈의 앞뒤 배치가 측면과 평면에서 다르고, Poseidon 삼지창은 정면과 측면에서 서로 다른 방향으로 표현된다. 이 모순을 모델의 뷰별 왜곡이나 원화 덮어쓰기로 숨겨서는 안 된다.
- 원본 캐릭터 시트를 최우선 기준으로 유지한다. 3면도를 현재 모델에 맞춰 바꾸고 일치했다고 주장하면 안 된다.
- 남은 시각 차이: 일부 부품 비율, 잎/날개와 장식의 면 형상, 바퀴 덮개, 눈과 얼굴의 표면 접합, 문양/이음새 상세. 단순 재질 교체로 완료 처리할 수 없다.

## 헤드리스 후속 1 — 2026-09-20

- 다음 검토 대상: 활의 측면 윤곽과 레일/클램프 모양, 타이어 단면과 목재 휠 외곽, 몸통에 붙는 잎 뿌리의 자연스러운 연결. 원본 시트 기준으로 확인할 것.

## 헤드리스 후속 2 — 2026-09-20

CrossBow의 활이 원형 호스 단면이던 문제를 실제 사각 단면의 적층 목재 활로 교체했다. 끝부분으로 갈수록 두께가 줄고 목재 층 이음이 활의 굴곡을 따라간다. 중앙 금속 고정부에 별도 띠와 리벳을 만들고, 나무 휠 외곽에 연속 고무 타이어와 12개 돌출 접지면을 추가했다. 정면 실제 렌더에서 단면과 고정부/바퀴 변화 확인. 최초 렌더에서 접지면 사이에 나무색이 보이는 문제를 발견하여 타이어 바탕도 고무 재질로 수정했다. 원화 자체는 변경하지 않았다. 형상 일치 기준은 여전히 미달이다.

다음에는 CrossBow만 반복하지 말고 Cannon의 뚜껑·눈썹 부착면과 실제 원화의 후방 고리, 또는 Carrot의 몸통 판 분할/잎 뭉치 등 다른 기종의 명확한 차이도 줄일 것. 활의 꺾인 구간은 현재 7개 단면이므로 곡률 보간을 더 개선할 여지가 있다.
