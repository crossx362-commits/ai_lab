# 전장 그래픽 개편 — 2026-09-19

밝은 동화풍 배경, 둥근 장난감 재질, 손그림 지면, 크림색 테두리와 청록색 GUI를 함께 적용했다.

## 이미지 원본과 연결

이미지는 내장 `image_gen`으로 제작했다. 전체 프롬프트는 `world-prompts.json`에 보관한다.

- `unity/Assets/_Project/Resources/Art/world-meadow.png`: 초원·계곡, 가을은 셰이더에서 잎 색을 변환한다.
- `world-desert.png`, `world-snow.png`, `world-volcano.png`: 사막·설산·화산. 눈 날씨에는 설산 원경을 사용한다.
- 같은 폴더의 `ground-grass.png`: 초원·계곡·가을의 잔디 질감. 사막과 눈에는 적용하지 않는다.
- `unity/Assets/_Project/Resources/Gui/story-skin.png`: 패널·버튼의 9-slice 원본. 기존 아이콘과 동적 글자·수치는 유지한다.

`MapTheme.PanoramaResource`가 배경 선택을 통합한다. `SkyGradient.shader`는 파노라마를 안쪽 스카이돔에 매핑한다. 가로 미러 래핑과 상·하단 색상 전환으로 경계를 처리한다. 스카이돔은 LateUpdate에서 모든 카메라 포즈를 따라간다. 원경 이미지가 없을 때만 기존 절차적 배경을 사용한다.

## 실제 게임 그래픽

- `TerrainVertexColor.shader`: 보간 법선과 부드러운 명암, 거리 안개, 잔디 질감. 지형 파괴·흙 노출은 기존 시뮬레이션과 팔레트를 그대로 사용한다.
- `Environment.BuildApronMesh`: 중앙이 열린 배경 구릉. 가장자리에만 0.5m 겹쳐 틈을 막는다. 플레이 영역을 덮지 않아 크레이터를 가리지 않는다. 콜라이더 없음.
- `SoftToy.shader`: 탱크와 식생의 색·명암 통일. 탱크는 작은 곡면에 생기는 자기 그림자 얼룩을 피하도록 그림자 수신을 끄되 지면에 그림자는 드리운다.
- 식생은 넓고 부드러운 수관으로 변경하고 8개 메시를 공유한다. 기존 스폰 회피·폭발 제거·바람 흔들림을 유지한다.
- `EnergyCurtain.shader`: 증폭벽을 투명한 격자 장막으로 표시한다. 판정 범위는 변경하지 않는다.
- 턴 순서는 상단 초상화 줄로 배치했다. 실제 순서·누적 딜레이를 읽는다.
- 탱크 초상화 13개를 새 게임 재질로 다시 렌더했다.

## 검증과 회귀 방지

`Tankfall.EditorTools.WorldArtVerify.Run`은 6개 맵 × 맑음/눈 테마의 원경 리소스, GUI, 셰이더와 배경 구릉의 면 방향·열린 중앙을 검사한다. 실제 플레이 증거는 별도 빌드 실행으로 확인한다.

이번 작업 중 Metal 셰이더의 예약어 `line` 충돌을 발견했다. Unity는 셰이더 오류 2개가 있어도 BuildReport.result를 Succeeded로 반환했다. `BuildScript`가 result와 totalErrors를 함께 검사하도록 수정했다. 오류 셰이더에서 종료 코드 1, `gridLine`으로 수정 후 오류 0·종료 코드 0을 확인했다. 빌드 성공 문구만으로 그래픽을 정상이라고 판단하지 않는다.

검증 로그와 실제 게임 캡처: `output/world-art/`. 이전 모델 개편 화면은 `output/remodel/`에 남아 있다.
