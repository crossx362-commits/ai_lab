# 그래픽 통합 개선 — 2026-09-19

## 방향
동화 속 장난감 탱크 전장. 남색·크림·주황 GUI, 밝은 에나멜 탱크, 청록 음영과 따뜻한 햇빛의 환경으로 구분한다.

## 적용
- 생성 이미지: `Resources/Gui/story-skin.png` 새 4칸 nine-slice 스킨. 중심부는 실제 UI 글자를 위한 빈 공간. `GuiArt`의 자르기 좌표를 실제 이미지에 맞췄다.
- 생성 이미지: `Resources/Art/world-meadow.png` 공중 섬·폭포·천문대 파노라마. 초원 테마 원경으로 사용하며 설원·사막·화산 테마 자원은 유지한다.
- 전투 하단: 탱크·각도 카드와 조작 콘솔을 분리, 전체 높이를 192에서 174로 축소. 체력·파워·이동 게이지는 평평한 내부 트랙으로 정리. 팀과 아이템 패널은 어두운 보조 스킨.
- 지형: 작은 잔디 무늬의 대비를 낮추고 넓은 색 영역을 추가했다. 전장 밖은 낮은 구릉을 유지하고 반복 잔디 무늬를 제거해 원경을 차분하게 정리했다. 전장 중앙 구멍과 크레이터는 덮지 않는다.
- Blender 탱크: 표정과 기종별 큰 장식 보강. 투석기/석궁 방패·깃발, 캐롯 잎 장식, 마인랜더 경고 도색, 미사일 포드 장갑, 슈퍼탱크 어깨 장갑·크라운, 레이저 안정익, 이온 궤도 장식, 포세이돈 지느러미·창, 세크윈드 날개. 포구·회전축은 유지.
- 재질: 탱크와 식생의 차가운 그늘·따뜻한 햇빛 대비 강화. 게임 재질로 13개 초상화를 다시 렌더링.
- 탱크 선택: 별도 RenderTexture 카메라로 회전하는 실제 3D 모델을 전시한다. 전장과 분리된 일러스트 배경, 더 큰 탱크 선택 카드. 퇴장할 때 카메라·텍스처·생성 재질을 정리하고 전투 카메라 마스크를 복원한다.

이미지 생성: 내장 imagegen. 원본은 Codex generated_images에 유지하고 게임 자원으로 복사했다. 현실 또는 원작 에셋을 복제한 것이 아니다.

## 검증 기록
- Blender 출력 39개, 730,762 삼각형. Unity에서 13개 회전축·포구·바퀴와 26종 발사체 검사 통과.
- `verify.sh compile` 통과. Mac 빌드 오류 0.
- `WorldArtVerify`: 12개 맵/날씨 조합 자원, 전장 바깥 메시의 열린 중앙·면 방향 검사 통과.
- UI 1440×900 / 1280×720 각각 11개 화면, HUD 비교 캡처 22/22 통과. 탱크 선택과 전투 전환을 포함한다.
- TwinHills 맑음 / Terrace 눈 / Crater 맑음 실제 자동 포격, 각각 비행·착탄 캡처 13/13 통과.
- 정적 장면 성능 검사 기준 1.41 ms 중앙값(해당 Mac, 1440×900, VSync 해제). 폭발이 겹치는 실제 플레이 최저 성능을 보증하는 수치가 아니다.
- 마지막 외곽 지형 구릉·무늬 조정 후 다시 빌드하고 TwinHills 포격을 재실행했다. 다른 두 맵과 UI 검사는 이 마지막 재질 인자 변경 전 결과다.

검증 로그: `output/art-polish/verification/`. 경쟁력은 주관적 아트 평가이며 자동검사 통과로 보증하지 않는다.
