# TANKFALL Blender 모델

`tankfall_roster.blend`에 탱크 13종과 일반탄·특수탄 26종이 각각 컬렉션으로 들어 있다. `exports/`에는 모델별 FBX가 있다. 외부 모델·텍스처를 내려받지 않고 Blender에서 제작했다.

## 게임 연결

- `View/BlenderModels.cs`가 `Resources/BlenderModels/*.json`에서 Blender의 확정 정점·노멀·삼각형·재질·계층을 읽는다. 런타임에 새 탱크 형태를 절차적으로 만들지 않는다.
- JSON은 Blender 외부 임포터와 축 변환 차이에 의존하지 않기 위한 메시 전달 형식이다. 편집 원본과 일반 교환 파일은 `.blend`와 `.fbx`다.
- 기본 차체색과 팀색은 기존 게임 재질을 사용하고, 기종별 장갑·무장 보조색은 Blender 재질과 런타임 팔레트에 동일하게 정의한다. 탄두·금속 띠·날개는 발사체 정점색에 보존한다.
- 포탑 yaw → 포신 pitch → FirePoint와 바퀴 회전축을 분리했다. 기존 발사 원점과 회전축을 유지하며 전투 수치는 변경하지 않는다.
- 눈 장식은 Snow 재질로 분리한다. 날씨가 눈일 때만 게임이 표시한다.
- 고정 부품은 부모·재질별로 묶되 바퀴·회전축은 합치지 않는다.

## 재생성

프로젝트 디렉터리에서:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/blender/build_models.py
```

생성기는 기존 `TankShape`에서 크기·회전축 기준을 읽는다. Unity 좌표는 X 오른쪽, Y 위, Z 전방이다. Blender 안에서는 Z-up으로 작업하고 내보낼 때 게임 좌표로 변환하고 외향 면 방향을 유지한다.

비교 렌더만 다시 만들 때:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/blender/render_models.py
```

Blender 비교 이미지는 `output/blender/`, Unity 렌더는 `output/blender/unity/`에 저장한다.

## 검증

Unity 메뉴 `Tankfall > Verify Blender Models`에서 39개 모델, 메시 인덱스·노멀·면 방향, 13종 회전축·발사 원점·바퀴, 발사체 26종의 형태 중복과 정점색을 검사한다. `Tankfall > Render Blender Model Review`는 같은 검사 후 **현재 씬을 빈 검토 씬으로 전환**하여 실제 게임 로더로 탱크·발사체를 렌더한다. 작업 중인 씬은 먼저 저장한다.

`bash tools/verify.sh compile`은 C# 컴파일 확인이다. 실제 게임 실행 증거는 별도의 빌드와 갤러리·사격 실행으로 확인한다.

면 방향 회귀 방지(2026-09-19): `(x,z,-y)` 변환은 determinant +1 회전이므로 삼각형을 추가 반전하지 않는다. `BlenderModelVerify`는 면 외적과 노멀의 양의 내적을 검사한다. 잘못 뒤집힌 Catapult에서 검사가 실패하는 것을 먼저 확인했다.

## 비율·배색 보정 — 2026-09-19

다연장 포드 폭·높이를 약 12~13% 줄이고, 레이저 레일 두께와 후방 하우징을 보강했다. 이온 접시와 세크윈드 날개·터빈을 축소하고 미래형 3종의 회전 하우징을 넓혔다. 회전축과 발사 원점은 유지한다. 13종에 크림·와인·청록·남색·금색·자주 보조색을 배치했고 팀 패널은 동적 팀색을 유지한다.

보정 후 Unity 검증: 39개 모델, 278,810 삼각형, 13종 회전축·발사 원점·주행 부품, 26종 발사체 검사 통과. C# 컴파일·Unity 비교 렌더·Mac 빌드(오류 0)·빌드 실행 로스터 13종 검사 통과. 위 전투 실행 기록은 최초 적용 시의 기록이다.

## 캐주얼 캐릭터 개편 — 2026-09-19

포트리스2를 참고해 13종에 둥근 차체·포탑, 두툼한 포구, 큰 눈·광택·볼·입을 Blender 메시로 조형했다. 표정은 차체, 무장은 기존 회전 계층에 속한다. Unity에서 같은 모델로 생성한 투명 초상화를 이미지 GUI에 사용한다. 원본 `.blend`, 39개 FBX 및 런타임 메시 데이터를 재생성했다. 최종 메시 검사: 39개 에셋 / 657,674 삼각형 / 13종 회전축·발사 원점·주행 부품 / 26종 발사체 통과. GUI 원본·프롬프트·연결은 `../gui/README.md` 참조.

## 차체 재모델링 — 2026-09-19

기존 평판 차체와 가는 스포크 바퀴를 교체했다. Superellipsoid 메시로 넓고 부드러운 차체 면을 만들고, 수레형은 두꺼운 컬러 휠과 보트형 몸체, 궤도형은 3개 대형 휠과 연속 벨트·에나멜 덮개, 트럭형은 둥근 운전석과 6륜, 호버형은 캡슐 몸체·하부 추진기를 사용한다. 앞면 표정은 차체 안쪽의 바이저 형태로 통합했다. 포구·발사대 두께와 크림·남색·와인·청록 보조색도 조정했다. 투석기와 쇠뇌는 전용 무기 받침을 사용한다.

재생성 경로와 회전축은 그대로 유지한다. 이 개편은 탱크 13종의 Blender 원본·FBX·Unity 메시와 해당 모델에서 렌더한 GUI 초상화에 반영한다. 기존 발사체 26종과 전투 능력 수치는 변경하지 않는다. 이전 모습은 `output/remodel/before.png`에 보관했다.

최종 검증: Blender 내보내기·비교 렌더 39개 통과, Unity 693,398 삼각형 및 13종 회전축·발사 원점 검사 통과, 13개 초상화 검사 통과. 정적 검사 전체 통과, Mac 빌드 오류 0, 실제 실행 로스터 13종·UI 11/11 및 캡처 22/22·포격 캡처 13/13 통과. 로그는 `output/remodel/verification/`, 실제 화면은 `output/remodel/ui/`와 `battle/`에 저장했다.
