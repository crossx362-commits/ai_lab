## 2. 조사 결론 6줄 (설계로 넘어가기 전)

1. **어그로는 「위협 표」와 「최근접」 둘 중 하나가 아니다.** 1차 자료가 실제로 정의하는 것은 ①몹별 **정렬된 리스트**(S1) ②그 리스트를 조작하는 동사 3개 — 최상단 세팅(Provoke) · 비율 전가(Shirk) · 생성 배율(스탠스) 뿐이다.
2. **위협 레이스를 게임플레이로 만들지 마라.** 블리자드가 스스로 내린 결론이다(S7) — "누가 맞고 있는가(aggro)"는 남기고 "누가 어그로를 뺏을 참인가(threat race)"는 내렸다. **자동 전투 게임에서는 애초에 플레이어가 참여할 수 없는 레이스다.**
3. **탱은 HP가 많은 게 아니라 경감 계층이 있는 것이다.** 상시 −20%, 액티브 −30~40%, 흡수 배리어, 즉사 방지, 아군 대신 맞기, **적을 깎아 파티 전체를 지키기**(Reprisal −10%)가 전부 다른 계층이다(S2·S3). HP만 늘리면 힐러의 초당 회복량이 유효 HP를 **곱셈으로** 늘려주는 구조가 생기지 않는다.
4. **힐러는 위협을 낮춰서 사는 게 아니다.** FFXIV 힐러 액션에 enmity 문구는 하나도 없다(S6). 힐러를 살리는 것은 **탱의 도발 주기**와 **자기 경감**이다.
5. **수백 체는 "전부 똑같이 굴리기"로 성립하지 않는다.** L4D는 개체를 재활용하고 팀 주변만 채우며, 강도가 높으면 **개체 수를 줄여서** 가독성을 만든다(S10). 헤일로는 20~25체에서도 "숨은 상태를 버려라"를 원칙으로 삼았다(S12).
6. **물량 속에서 탱을 살리는 방법은 어그로 규칙이 아니라 쫄의 분류다.** "탱이 잡아야 하는 것"과 "나머지를 묶어두는 것"을 **디자이너가 나눠서 스폰한다**(S9).

### 3-4. ⚠️ 코드 정독으로 발견한 결함 3건

> 셋 다 **기획서 §10-4를 코드가 어기고 있는** 사례다. 유니티를 못 돌리므로 아래는 **산술과 정독**의 결과이며, §6-1의 S1 단계가 이를 계측으로 확정한다.

#### ① 위협에 상한이 없어 「근접 = 최근접」(✅§10-4)이 약 10초 뒤 무너진다

`PickNearestOrTaunt`의 점수는 `거리(유닛) − 위협×0.12`다. **서로 다른 단위를 뺀다.**

| 파티원 | 위협 생성률 | 감쇠 | 순증 | 100초 후 위협 | 거리 환산(×0.12) |
|---|---|---|---|---|---|
| 검사 | 평타 `26×0.4=10.4` / 0.35s, 5타마다 일섬(`83.2×0.4=33`) → **≈42/s** | −2/s | **+40/s** | ≈4,000 | **480 유닛** |
| 마법사 | `10.4` / 0.40s → ≈26/s | −2/s | +24/s | ≈2,400 | 288 유닛 |
| 수호기사 | 평타 ≈5.7/s + 도발 `80/6s` ≈13/s → **≈19/s** | −2/s | +17/s | ≈1,700 | 204 유닛 |

아레나 반경은 **14**다. 즉 **10초쯤부터 거리항(최대 28)이 위협 격차에 완전히 묻히고**, 모든 근접 몹이 위치와 무관하게 **검사 한 명**에게 간다. 탱의 도발 +80은 9.6유닛어치라 이 격차를 못 뒤집는다.

📌 §21-1i의 「D(도발OFF)가 판이 길어질수록 효과가 작아진다」는 관찰의 **가장 유력한 설명**이다. 도발의 위협 성분은 초반 2~3초만 유효하고, 실제 효과는 원거리 몹 3초 하드 락(A9)이 거의 전부다.

#### ② `PickBackline`의 부호가 반대다 — 후열이 아니라 **최고 위협 딜러**를 노린다

```
float s = m.MaxHp - m.Threat * 6f;   // 주석: "HP 낮고 위협 낮은 쪽"
if (s < score) { score = s; best = m; }   // 최솟값을 고른다
```

`Threat`에 **−**가 붙어 있으므로 위협이 높을수록 점수가 낮아지고 → **선택된다.** 주석이 말하는 것과 정반대다.
게다가 위협이 전부 0이어도 MaxHp는 검사·마법사 **130** < 사제·음유시인 **150**이라 **딜러가 먼저 뽑힌다.**
✅§10-4는 "가장 약한 후열(힐·버퍼) 우선 저격"이라고 못 박았다. **현행 코드는 원거리 몹이 힐·버퍼를 노린 적이 한 번도 없다.**

#### ③ 「후열피격」 지표가 딜러와 지원을 구분하지 않는다

`Damage(tgt, dmg, tgt.Role == Role.Tank)` — **탱이 아니면 전부 후열**이다.
§21-1i의 A 구성 「후열피격 644 / 전열피격 212」는 ①·②를 감안하면 **검사가 대부분 맞고 있다**는 뜻일 가능성이 높다. 이 지표로는 "탱이 어그로를 잡고 있는가"를 판정할 수 없다. §6-1 S1이 이것부터 고친다.

## 4. 권고 설계 — 자동 전투 + 500체 + 영구사망에 맞는 규칙

> 설계 제약 3개가 모든 판단을 지배한다:
> **①플레이어는 잡몹 구간에서 아무것도 안 누른다**(✅§5) → 플레이어 조작을 전제한 기법 전부 탈락
> **②화면에 수백 체가 있다**(💡§10-9) → 개체별 상태가 늘면 디버깅·성능이 동시에 무너진다
> **③죽으면 캐릭터가 사라진다**(✅§4) → "왜 죽었는지 안 보이는 죽음"은 이 게임에서 최악의 결함이다(S12의 가독성 원칙이 여기서 안전장치가 된다)

### 4-1. 규칙 R1 — 위협은 **거리를 대체하지 않는다.** 세 곳에서만 쓴다

✅ **기획서 §10-4가 이긴다: 근접 몹은 최근접이다.**
따라서 위협을 근접 타겟 선정의 **주항으로 쓰지 마라**(현행 결함 ①). 위협은 아래 세 곳에서만 쓴다:

| 쓰이는 곳 | 규칙 |
|---|---|
| ① 근접 몹의 **동률 타이브레이크** | 최근접 후보가 💡**1.0유닛 이내로 여럿**일 때만 위협 높은 쪽. 그 밖에는 순수 거리 |
| ② 원거리 몹의 **저격 대상** | §4-3 |
| ③ **보스**의 어그로 타겟 | §4-7 |

💡 1.0유닛 유도: `UnitSeparation` 반경이 0.5라 유닛 지름이 1.0이다 — "붙어 있는 둘"의 자연 단위.

⚠️ 그러면 탱은 어떻게 앞에 서는가? **위협이 아니라 위치와 물리로** 선다:
- 탱만 정지 거리 없이 최근접 몹에게 붙는다(현행 `TickParty` L1015-1017 유지)
- 검사는 `Range×0.9 = 1.71`에서 멈추고, 마법사·사제·음유시인은 `KeepDist` 뒤에 선다(현행 유지)
- `UnitSeparation`이 몹이 탱을 **통과하지 못하게** 막는다 → 탱이 물리적 벽이 된다

이것이 이 게임에서 탱이 성립하는 진짜 이유이며, 위협 시스템보다 **훨씬 튼튼하고 눈에 보인다**(S12).

### 4-2. 규칙 R2 — 위협은 **비율 감쇠**로 정상상태를 갖는다 (결함 ① 근본 수리)

```
Threat *= exp(-dt / τ)      // 선형 -2/s 를 교체
```

💡 **τ = 8초.** 그러면 정상상태 위협 = 생성률 × τ 로 **수렴하고 발산하지 않는다.**

| 파티원 | 생성률 | 정상상태(×8) |
|---|---|---|
| 검사 | 42/s | 336 |
| 마법사 | 26/s | 208 |
| 수호기사(스탠스 없이) | 19/s | 152 |
| 수호기사(스탠스 ×3, §4-4) | 57/s + 피격분 | **456 +** |

💡 τ=8 유도: 도발 쿨이 ✅6초(현행)이므로 **한 번의 도발 효과가 다음 도발까지 살아 있어야** 어그로가 끊기지 않는다. τ가 쿨보다 짧으면 도발 사이에 구멍이 생기고, 훨씬 길면 초반 우연이 판 전체를 지배한다. τ ∈ [쿨, 쿨×1.5] → 6~9초 → **8초**.

### 4-3. 규칙 R3 — 원거리 몹의 저격 대상을 §10-4대로 되돌린다 (결함 ② 수리)

✅§10-4 "가장 약한 후열(힐·버퍼) 우선". 부호를 고치고 역할을 명시한다:

```
score = 역할가중(m) × (1 + Threat_m / T_ref)      // 최댓값을 고른다
역할가중: 힐 1.00 · 버퍼 0.90 · 원거리딜 0.55 · 근접딜 0.35 · 탱 0.15
T_ref = 400            // 정상상태 최댓값(§4-2) 근처
```
💡 역할가중 유도: ✅§10-4가 "힐·버퍼 우선"이라 했으므로 둘이 최상위. 딜을 0으로 두면 힐러가 죽는 순간 원거리 몹 전원이 버퍼로 몰려 **한 명씩 도미노로 지워지는 그림**이 되므로 0이 아닌 값을 준다. 탱은 최하위여야 도발(§4-5)이 의미를 갖는다.
⚠️ 위협항을 곱으로 두는 이유: 더하기로 두면 결함 ①과 같은 단위 혼합이 재발한다.

### 4-4. 규칙 R4 — 탱 스탠스: **위협 배율 + 맞아준 만큼 위협**

1차 자료에서 탱 스탠스는 언제나 **곱셈 배율**이다(S1 Iron Will · S3 Defiance · S7 "three times → five times damage done" · S18).

💡 수호기사 상시(스탠스 토글 없음 — 자동 전투라 켤 사람이 없다):
```
위협 += (준 피해 + 받은 피해 × 0.5) × 3.0
```
💡 **배율 3.0** 유도: S7이 블리자드의 **하한값(3배)과 상향값(5배)** 을 둘 다 준다. 이 게임은 위협 레이스를 게임플레이로 만들지 않으므로(§2-2) 상향판(5배)이 필요 없다 → **하한값 3.0**에서 시작하고, §6의 「탱 피격 비중」이 목표에 미달하면 5.0까지 올린다.
💡 **받은 피해 × 0.5** 유도: ✅§3이 수호 게이지를 "피격·아군 보호 시 축적"으로 정의했고 코드가 이미 `자기 피격 ×0.5`를 쓴다(`Damage` L1493). **같은 계수를 재사용해 축을 하나로 유지한다** — 게이지와 위협이 같은 사건으로 자란다.

⚠️ 이 규칙은 자기강화 루프를 만든다: 맞으면 → 위협↑ → 더 맞음. **그게 의도다.** 반대로 탱이 안 맞으면 위협이 τ로 빠지고 어그로를 놓치는데, 그 구멍을 도발이 메운다(§4-5).

### 4-5. 규칙 R5 — 도발은 **하드 락 + 최상단 세팅**이다 (결함 ①의 실효 회복)

현행 `Threat += 80`은 §3-4 ①에서 본 대로 몇 초 만에 무의미해진다. S1의 Provoke 정의를 그대로 쓴다 — "**placing yourself at the top** of a target's enmity list **while gaining additional enmity**":

```
도발(반경 R, 지속 D):
  반경 안 모든 몹: 타겟 := 탱  (하드 락, D초)
  탱.Threat := max(탱.Threat, 파티최고위협 × 1.2)
```
| 값 | 제안 | 유도 |
|---|---|---|
| 반경 R | 💡 **6.5** | 원거리 몹의 유지거리가 `keep = 6.5`(`TickMobs` L1385)다. 그보다 좁으면 **도발이 원거리 몹에 절대 안 닿는다** — ✅§10-4가 "후열 저격을 끊는 유일한 수단"이라 한 것이 성립하려면 이 값이어야 한다 |
| 지속 D | ✅ **3.0초**(현행 유지) | 기획서가 "강제 타겟 N초"만 정했고 코드가 3.0. 바꿀 근거 없음 |
| 쿨 | ✅ **6초**(현행 유지) | 듀티사이클 50% — 락이 풀린 3초 동안은 위협 우위(×1.2)가 버텨야 한다. 이게 §4-2의 τ가 필요한 이유 |
| 발동 조건 | ✅ 현행 유지 (`반경 4.5 안 몹 ≥ 3` 또는 버튼) | ⚠️ 판정 반경 4.5와 효과 반경 6.5가 다른 것은 **의도다** — 붙은 무리가 3체 이상일 때 켜서 멀리 있는 사수까지 끌어온다 |

📌 **하드 락을 근접 몹에도 건다.** 현행은 원거리에만 걸려 있다(A9). 근접은 어차피 최근접(R1)이라 대개 탱을 보고 있지만, 검사가 앞으로 튀어나간 순간을 되돌리는 것이 도발의 역할이다.

### 4-6. 규칙 R6 — 탱 경감을 계층으로 만든다 (M4 공백 메우기)

현행 탱의 방어력은 **HP 320 대 딜 130**이 전부다. HP만으로는 힐러가 곱셈 이득을 못 낸다.

| 계층 | 제안 | 유도 · 근거 |
|---|---|---|
| 상시 피해 감소 | 💡 수호기사 **−20%** | S2 Rampart(모든 탱 공용 역할 액션)가 정확히 20%다. **"모든 탱이 항상 켤 수 있는 최저선"**이라는 위치가 우리의 상시치와 같다 |
| 흡수 배리어 | ✅ 성채 방패 **40**(현행 유지) | ✅§3. §18-11 기준 잡몹 1대 6이므로 **약 7대분** — S2 Divine Veil이 "최대 HP의 10%"인 것과 비교하면 탱 기준 12.5%로 같은 자릿수 |
| 즉사 방지 | ✅ 최후의 보루 3s/60s(현행 유지) | ✅§3 · S3 Holmgang(10초/4분)의 축소판 |
| 파티 오라 | ✅ 수호가 ×0.82(현행 유지) | ✅§3 · S2 Passage of Arms(85%)와 같은 자릿수 |
| 적을 깎는 경감 | 💡 주술사 도입 시 **적 공격력 −10%** | ✅§3 "무기력의 저주(적 공깎)" · S3 Reprisal이 정확히 −10% |

💡 **−20%가 왜 HP 증가보다 나은가 (수치 유도)**: 탱 320HP, 잡몹 1대 6, 동시 공격자 5체(§3-3 H3) → 초당 30 피해.
- HP만 늘려 400으로: 생존 13.3초. 힐러 단일힐 24/1.0s를 얹으면 `30−24=6/s` → 66초.
- HP 320 + DR 20%: 피해 24/s. 힐 24/s를 얹으면 **순 0/s → 무한 유지**.

**같은 힐량이 DR과 곱해질 때만 「힐러가 있으면 탱이 안 죽는다」가 성립한다.** ✅§9 "힐러 없이는 소모전에서 진다"를 수치로 만드는 것이 바로 이 곱셈이다.
⚠️ 이 규칙은 §21-1i의 `E(힐러없음)/A = 0.67`을 **더 낮출 것으로 예측된다.** 그게 검증 지표다(§6-1 S6).

### 4-7. 규칙 R7 — 보스에게 어그로 타겟을 준다 (H13 공백)

현재 보스는 파티원을 **타겟으로 갖지 않는다.** 그래서 ✅§10-7 "다중 보스는 탱 1명으로 다 잡을 수 없다 → 탱 2명 편성이 처음으로 의미를 갖는다"가 코드에서 성립할 수 없다.

💡 최소 구현:
| 보스 행동 | 대상 선정 |
|---|---|
| 근접 평타 | 위협 1순위 (= 도발한 탱) |
| 대상 지정 광역(✅§10-5 #3) | 위협 **2~3순위 중 무작위** — 탱이 아닌 사람에게 가야 "떨어져라"가 지시가 된다 |
| 지속 광역딜(✅§10-5 #4) | 전원(대상 선정 없음) — 현행 힐 체크 그대로 |
| 쫄(✅§10-5 #2) | **실제 몹으로 스폰**해 §4-1~4-5 규칙을 그대로 탄다. S9의 분류를 따라 **탱이 잡아야 하는 쫄**(고HP·근접)과 **나머지를 묶는 쫄**(원거리·후열 저격)로 나눠 스폰한다 |

⚠️ **탱 스왑은 아직 넣지 마라.** 1차 자료가 「누적 스택 → 스왑」 인과를 정의하지 않는다(§1-2). 대신 ✅§10-7의 **다중 보스**가 이미 탱 2명을 요구하므로, 그것부터 성립시키고 스왑은 그 뒤에 판단한다.

### 4-8. 규칙 R8 — 500체는 「더 많이」가 아니라 「더 싸게 + 덜 겹치게」다

| 항목 | 제안 | 근거 |

| **액티브 미티게이션**(플레이어가 누르는 경감 쿨다운 — S2 Sentinel·Sheltron 계열) | ✅§5가 조작을 **보스전에서 이동+스킬 2종**으로 못 박았고 잡몹 구간은 **완전 자동**이다. 자동 AI가 대신 눌러주면 그건 액티브 미티게이션이 아니라 그냥 조건부 패시브다 — **같은 결과를 상시 DR(§4-6)로 얻으면서 UI·튜토리얼·오조작 비용을 0으로 만들 수 있다** |
| **위협 미터 UI / 위협 레이스** | 블리자드가 스스로 내린 결론이다(S7: "threat races … going to be downplayed"). 게다가 **플레이어가 딜을 조절할 수단이 없는 게임**에서 위협 레이스는 관전 스포츠다 |
| **딜러의 위협 감소 스킬**(Fade/Feint 계열) | 위와 같음. 누를 사람이 없다. 대신 §6-1 S7의 **자동 전가**로 같은 효과를 얻는다 |
| **몹별 완전한 위협 테이블**(500 × 5 = 2,500칸) | 저장은 가능하나 ①매 갱신 비용 ②**디버깅 불가능**(왜 저 몹이 저기로 갔는지 사람이 못 읽는다). S12의 "Discarded: Hidden States"가 정확히 이 이야기다. **파티 5칸 위협 + 몹별 타겟 포인터 1개**로 같은 표현력을 낸다 |
| **L4D식 Relax 구간**(위협 개체 0)(S10) | L4D는 이동 게임이라 정적을 만들 수 있다. 이 게임은 **뱀서라이크**라 압력이 끊기면 장르가 무너진다. ✅ 다만 **차용할 것 하나**: "교전 중에는 강도를 감쇠시키지 마라"(Peak Fade) — 웨이브 압력을 시간이 아니라 **교전 상태**로 게이트하는 것은 유효하다 |
| **어그로 반경 · 리쉬 · 귀환** | 뱀서류는 화면의 전부가 플레이어로 수렴하는 것이 장르 문법이다. 리쉬를 넣으면 §21-1c에서 이미 반증된 **"도망이 지배 전략"** 이 되돌아온다 |
| **탱 스왑 · 누적 취약 스택** | 1차 자료가 이 인과를 정의하지 않는다(§1-2). ✅§10-7의 다중 보스가 이미 탱 2명을 요구하므로 **더 싼 수단으로 같은 목적**을 달성한다 |
| **GW2식 불투명 어그로**(방어력·거리·무작위 혼합) | 500체 화면에서 규칙이 안 읽히면 **진형 자체가 화면에서 사라진다**(S12). ⚠️ 단 GW2의 실제 설계는 1차 자료로 확인 못 했다(§1-2) — 이 항목의 근거는 GW2가 아니라 **S12의 가독성 원칙**이다 |
| **탱의 HP를 더 올리기** | §4-6의 유도가 보여주듯 HP는 힐량과 **더해지고**, DR은 **곱해진다**. 힐러의 가치를 만드는 것은 곱셈뿐이다 |
| **정예를 6종 다 넣기** | ✅§10-2가 이미 금지했다 — "웨이브당 정예 유형은 1~2종만". H5의 공백(수호자·처형자·저주술사 부재)은 채우되 **동시 등장은 2종 상한** |
