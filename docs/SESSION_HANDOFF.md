```bash
# 스크린샷을 찍는 모드(-autoshot · -uiselftest · -gallery · -shellgallery)는 반드시 open 으로:
open -a "$PWD/unity/Build/Tankfall.app" --args -autoshot -shotdir /tmp/caps \
  -screen-width 1600 -screen-height 900 -screen-fullscreen 0 -logFile /tmp/caps/run.log
```
⚠️ **스크린샷 모드는 `open -a` 로 띄워라. 바이너리를 직접 부르면 캡처가 전부 실패한다**(2026-09-18 실측).
   로그에 `Failed to capture screen shot` 이 11줄 찍히고 자체검사가 `누락 11/11` 로 떨어진다 —
   파일이 안 생기니 조용히 통과하지는 않지만, 원인이 안 보여서 빌드가 깨진 줄 알기 쉽다.
   `-nographics` 도 같은 이유로 금지다(PNG 가 전부 새까맣게 나오는데 로그는 통과로 찍힌다 — unity_build.sh 머리말).
⚠️ 실행 파일 이름은 **`Contents/MacOS/unity`** 다(`Tankfall` 이 아니다 — 유니티가 그렇게 굽는다).
   경로를 직접 쓸 일이 있으면 그쪽이다.

게임 자체검사(전부 rc=0 이어야 한다):
`-supplyselftest | -ultselftest | -impairselftest | -climateselftest | -boomselftest | -rosterselftest | -practiceselftest | -gameselftest`
이것들은 화면을 안 찍으므로 `-batchmode -logFile <경로>` 로 직접 불러도 된다.

⚠️ 실행 중인 `verify.sh` 를 편집하지 마라(bash 는 실행하며 읽는다).
⚠️ 무인 모드를 새로 만들면 **`headless` 목록에만** 추가하면 된다 — 플래그를 하나씩 켜던 방식이라
   `-uiselftest` 등 넷이 `_autoMode` 를 못 켜서 화면이 통째로 멈춘 적이 있다(로그도 안 나온다).
