## 동시 개발자 (오너 공지 2026-09-08, 대장 경로)
**Grok이 같은 저장소(origin/master)에서 동시에 개발 중이다.** 출처 불명 변경은 결함이 아니라 Grok
작업일 수 있으므로 **반려·되돌리기 대상에서 제외**하고 **대장에 경로만 올린다**. 루프에는
`pull --rebase`·한 호흡 커밋·상대 변경 보존 규칙이 전달됐다.
**단, 이것이 결함을 통과시키는 구멍이 되면 안 된다** — 화면·게이트에서 잘못된 것은 **작성자와 무관하게
여전히 결함이다.** 달라지는 것은 **대응**뿐이다: 루프에 되돌리라고 지시하지 말고, **경로와 증상만
대장에 올린다.** 「Grok이 했나 보다」로 판정을 접으면 그게 곧 빈 통과다.
