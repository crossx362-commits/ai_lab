## ⚠️ 컴파일러가 안 잡아주는 함정

- **`AiGunner.Target.Kind` 를 안 채워도 컴파일된다.** 기본값이 캐터펄트(0)라 **포세이돈 독 저항 50% 만
  조용히 빠진다.** 재중독 판정은 Id 만 쓰므로 나머지는 멀쩡히 돌아 더 안 보인다.
  `new AiGunner.Target { ... }` 를 새로 쓰면 **반드시 `Kind = o.Kind` 를 넣어라**(현재 7곳 전부 채워져 있다).
- **`PickShell` 의 `status` 는 기본값 없는 필수 인자다.** 일부러 그렇게 뒀다 — 기본값을 주면 한쪽 호출부가
  안 넘겨도 컴파일이 되고, 게임만 고쳐지고 하네스는 옛 값으로 재는 어긋남이 생긴다.
  **빈 인스턴스를 새로 만들어 넘기지 마라.** 판 전체를 살아온 그것을 넘겨야 한다
  (`BattleDemo._status` · `BattleSimVerify.status`).
- **행 필터를 걸면 미러 게이트가 건너뛰어진다.** 기능을 넣은 커밋은 반드시 필터 없는 `verify.sh battle` 로
  한 번 돌려라(`TANKFALL_ROW=...` 만 돌리고 "전체 통과"라고 보고한 사고가 있었다).
- **평가와 적용은 같은 함수를 봐야 한다.** 독 저항은 `StatusEffects.PoisonAfterResist` 하나뿐이고
  적용(`Poison`)·평가(`PoisonGain`) 양쪽이 그걸 부른다. 식을 베껴 두면 한쪽만 낡는다.
- **가설로 고치지 말고 재라.** 크로스보우 최하위의 원인을 두 번 잘못 짚었고 스윕이 둘 다 뒤집었다:
  `SpBase` 38·38·37% / `DirectDamage` 39·46·48% / **`CraterRadius` 37·48·56%** — 진짜는 굴착(낙하 피해)이었다.
  "2번탄을 안 쓴다"·"AI 평가식이 틀렸다" 는 둘 다 **틀린 가설**이었다(`AiGunner.EffectValue` 머리말에 실측표가 있다).

- ✅ ~~M1 감각 판정~~ — **2026-09-19 오너 판정 «해봤는데 감 잡히더라 계속 진행해» 로 통과**(§11 M1).

## 열려 있는 것

0. ✅ **연습장 게이트는 고쳤다**(2026-09-19). 원인은 **역산이 기후를 안 보고 풀었던 것**이다 —
   `TrySolvePractice` 만 `ProjectileSimulator.Simulate` 에 `_air` 를 안 넘겨서, 역산은 회오리가 **없는**
   하늘에서 풀고 실제 발사는 회오리가 **있는** 하늘로 쐈다. 그래서 "검증통과" 해가 10% 확률로 거짓말을 했다.
   진짜 명중률 89.9% 가 게이트 90% 와 정확히 겹쳐 실행마다 rc 가 뒤집혔다.
   수리 후 **104발 100%**, 게이트를 100% 로 올렸다. **다시 내리지 마라 — 내리는 건 고장을 숨기는 것이다.**

   🚨 **여기서 내가 한 판별 실수를 기억하라.** 나는 이 가설을 한 번 세웠다가 "연습장 로그에 회오리가
   0건"이라며 **반증했다.** 그런데 그 로그(`_log += "[회오리]"`)는 바로 다음 줄에서
   `_log = "... 발사 —"` 로 **덮어써지는 줄**이었다. 즉 **거짓 음성으로 맞는 가설을 버렸다.**
   → **덮어써지는 값으로 판별하지 마라.** 판별은 그 순간의 값을 따로 찍어서 해라
   (결국 역산 착탄 좌표와 실제 착탄 좌표를 나란히 찍자마자 1분 만에 잡혔다).

1. **하단 두 기종 — 노이즈인지 먼저 확인할 것.** 듀크 37% · 세크윈드 38% 가 ⬇ 로 뜨는데, 직전 측정에서는
   39·39% 였다. 셀당 20판(±11%p)이라 **지금 수치로 손대면 노이즈를 쫓는다.**
   `TANKFALL_ROW=<Kind>` 로 40판 이상에서 재현부터 하고 움직여라.
2. **`[6-3]` 난이도 사다리의 "인접 난이도 차이가 안 난다" 경고** — 판정은 경고일 뿐 rc 에 영향 없다.
   셀당 20판이라 위 1번과 **같은 종류의 표본 문제**일 가능성이 높다. 판수를 올리거나 시드를 분리해
   재현성부터 확인할 것.
3. **미구현 큐: 네트워크(M5)** — 오너 지시로 뒤로 미뤘다.
4. **듀크 각도 상한(40°)** — §2-9-5 실험 6 결론 그대로 열려 있다. 원작이 0~40° 라면 고칠 곳은
   탱크가 아니라 맵이라는 판단도 그대로.
5. **v6 12×12 전체표를 명세에 정식 기록할지** 는 선택(§2-9-6 에 요약은 반영됨).
6. `AiMover` 의 사거리 확보(④)는 **수평거리만** 본다. 고저차로 실제 사거리가 줄어드는 건 안 센다.

### 오너 판단이 필요한 설계 질문 (수치가 아니라 규칙이라 손대지 않음)
실제 게임(§52)은 **팀A 가 항상 선공**이고, 실측으로 그 가치가 중급 난이도에서 약 **±10%p**,
고수끼리는 **±22%p** 다. PvP 에서 한쪽이 고정으로 이 이점을 갖는 게 의도인지, 아니면 선공을
무작위·교대로 돌리거나 후공에게 보정을 줄지 결정이 필요하다.
