## ⚠️ 오너 판단이 필요한 설계 질문 (수치 아니라 규칙이라 손대지 않음)

| 시드 | 기종별 시드 분리 **전** | 분리 **후** |
|---|---|---|
| +0 | 44.9% ❌ | 51.7% ✅ |
| +7 | 54.2% | 50.8% ✅ |
| +13 | 45.7% | 49.7% ✅ |
| +29 | 49.6% | 53.1% ✅ |
| **표준편차** | **4.2%p** | **1.5%p** |

**진짜 원인**: 게이트가 12종 전부에게 **같은 시드열**(`1000 + m*77`)을 먹이고 있었다. 같은 바람·같은 나이스샷·같은 투하가 12종에 통째로 걸려 720판이 서로 독립이 아닌데, 표준오차는 독립인 양 √720 으로 계산했다 — **±1.9%p 라고 주장하면서 실제 흔들림은 ±4%p**. 기종마다 시드열을 떼어(`+ (kind+1)*9973`) 12개가 진짜 독립 표본이 되게 고쳤고, 그러자 네 시드 전부 50% 근방(SD 1.5%p)으로 모여 식과 맞았다.

**보급은 무죄다.** 팀별 분해에서도 획득 A 0.23 : B 0.20 로 대칭이었다(그때 이미 단서였다). 이 프로젝트에서 표본을 과신해 오진한 게 이번이 **세 번째**다 — 이번엔 수치가 아니라 **오차 추정 자체**가 틀렸던 경우다.
