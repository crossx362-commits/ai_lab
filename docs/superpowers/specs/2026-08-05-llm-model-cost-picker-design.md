# AI Model & Cost Picker — 설계 문서

**작성일**: 2026-08-05
**목표**: 오너의 "혼자서 100만원 벌어와" 지시에 따른 독립 수익화 프로젝트. 불법/타해 없음, 계정·결제는 오너가 개설, 나머지는 클로드가 전담.

## 1. 문제

AI 앱을 만드는 개발자는 "이 작업엔 어떤 모델(Claude/GPT/Gemini 등)을 써야 하나", "월 비용이 대략 얼마 나올까"를 매번 여러 사이트를 돌며 수동으로 계산한다. 가격표는 자주 바뀌고, provider별 단위(1K vs 1M 토큰)도 달라 비교가 번거롭다.

## 2. 타겟 사용자

개인/소규모 팀 단위로 LLM API를 붙여 제품을 만드는 개발자(글로벌 영어권 우선 — 한국 시장보다 모수가 큼).

## 3. 해결 방식 (MVP 범위)

정적 웹앱 하나:
- **입력**: 예상 요청 수/월, 평균 입력·출력 토큰 수, 우선순위(비용/품질/속도/컨텍스트 길이)
- **출력(무료)**: 주요 모델 5~8종(Claude Haiku/Sonnet/Opus, GPT-4o/mini, Gemini 등)의 예상 월 비용 표 + 추천 모델 1개 하이라이트
- **출력(프리미엄, 라이선스 키로 잠금 해제)**:
  - 전체 모델 비교 리포트 내보내기 (Markdown / CSV — 외부 라이브러리 의존 없음)
  - 여러 시나리오(예: MVP/성장기/스케일업) 동시 비교
  - 프롬프트 캐싱 적용 시 절감액 계산

## 4. 수익화

**결제: PayPal Orders API 일회성 결제** (오너 지시 2026-08-05 — 당초 Gumroad 안에서 변경).

- 가격: 1회성 $9~12 선, 추후 트래픽 보고 조정
- 흐름: 서버리스 함수가 PayPal 주문 생성 → 사용자를 PayPal로 리다이렉트 → 결제 후 콜백에서 캡처 → 라이선스 키 발급
- **라이선스 키는 DB 없이 서명으로 검증한다**: `키 = PayPal주문ID + "-" + HMAC-SHA256(서버시크릿, 주문ID) 앞 10자리`.
  서버가 같은 시크릿으로 재계산해 대조하므로 구매 기록을 저장할 필요가 없다 — "런타임 의존성 0개" 제약 유지.
- 무료 버전만으로도 가치가 있어야 트래픽이 옴 → 프리미엄은 "내보내기/저장/멀티 시나리오"처럼 헤비유저에게만 필요한 기능으로 한정

**이 방식이 포기하는 것 (의도된 트레이드오프)**:
- 환불·차지백 시 키가 자동 무효화되지 않는다. $9 상품에서 DB를 두는 비용보다 이 손실이 작다는 판단.
  필요해지면 `api/verify-license`에서 PayPal 주문 상태를 조회하는 2차 검사를 덧붙일 수 있다(코드 변경만, 스키마 불필요).
- `PICKER_LICENSE_SECRET`을 잃거나 바꾸면 **발급된 모든 키가 무효화된다**. Vercel 환경변수에만 두고 로테이션하지 않는다.
- Gumroad와 달리 PayPal은 merchant of record가 아니다 → **디지털 상품 판매에 대한 부가세(EU VAT 등) 의무가 판매자에게 있다.** 오너 확인 필요 사항.

## 5. 기술 스택

- 순수 HTML/CSS/JS (프레임워크 불필요, 배포 단순화 우선)
- 가격 데이터: `data/pricing.json` 하드코딩 — 분기마다 수동 갱신(클로드가 최신 가격 리서치 후 갱신)
- 호스팅: Vercel (무료 티어 — 정적 사이트 + 서버리스 함수 3개: 주문 생성·결제 캡처·라이선스 검증)
- 내보내기: Markdown/CSV 문자열을 Blob으로 생성해 다운로드 (외부 라이브러리 0개)
- 테스트: Node 내장 러너(`node --test`) — 순수 계산 로직 단위 테스트, 의존성 0개

## 7. 범위 밖 (이번 단계에서 안 함)

- 사용자 계정/로그인 (라이선스 키만으로 충분)
- 실시간 가격 API 연동 (수동 갱신으로 시작, 트래픽 생기면 재검토)
- 다국어 지원 (영어 단일)
- 자동 마케팅 게시 (콘텐츠 초안은 클로드가 만들되, 실제 게시/발송은 매번 오너 승인 필요 — 안전 규칙)

## 8. 성공 기준

- 배포된 무료 도구가 실제로 작동하고 정확한 비용 계산을 제공
- PayPal 샌드박스 결제 → 라이선스 키 발급 → 프리미엄 unlock 흐름이 end-to-end로 검증됨
- 매출 자체는 트래픽에 달려 있어 보장 불가 — 클로드는 제작+배포+마케팅 초안까지 책임, 계정 승인·게시는 오너 몫
