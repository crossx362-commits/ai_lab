# 전투 보상 루프 HUD 설계

## 목표

전투의 시선을 중앙 전장에 두면서, 처치·드랍·성장·궁극기 충전이 반복적으로 보이는 방치형 RPG 전투 HUD를 만든다.

## 확정 방향

사용자가 선택한 `보상 루프형` 레이아웃을 적용한다. 화면의 주인공은 캐릭터·몬스터·전투 이펙트이며, UI는 전장과 겹치지 않는 세 개의 안전 영역으로 한정한다.

## 화면 구역

1. **상단 안전 영역 (높이 72px):** 스테이지, 현재 웨이브, 자동 전투, 배속. 보스가 있을 때만 그 아래 24px에 보스명·체력 바를 표시한다.
2. **중앙 전장 보호 영역:** 좌우 12%, 위 96px, 아래 148px를 제외한 영역이다. 캐릭터, 몬스터, 월드 VFX와 수치 콜아웃만 표현한다.
3. **우측 보상 레인 (폭 170px, 상단 104px부터):** 최근 보상 최대 3건, 킬 스트릭, 초당 골드를 표시한다. 각 항목은 2.2초 뒤 사라진다.
4. **하단 지휘 안전 영역 (높이 148px):** 중앙의 소형 파티 카드와 우측의 스킬/궁극기 버튼만 표시한다.

## 간섭 방지 규칙

- 월드 이펙트는 `FxPool.FrontSortingOrder`를 계속 사용하며 IMGUI HUD와 좌표를 공유하지 않는다.
- 전투 콜아웃은 중앙 보호 영역으로 클램프해 상단 보스 바, 우측 보상 레인, 하단 카드 위로 올라가지 않는다.
- 보상 문구는 우측 레인에 최대 세 줄만 유지한다. 새 항목은 위로 밀고 오래된 항목은 투명해진다.
- 하단 카드에는 초상화, 체력 바, 사망, 선택 상태만 둔다. 상세 로그와 스킬 설명은 표시하지 않는다.
- 해상도가 좁으면 파티 카드는 축소하고 우측 보상 레인은 2줄로 제한한다.

## 데이터와 연결

- `W3Party`의 기존 `_kills`, `_t`, `_party`, `_sel`, `ForceSkill`, `ForceUltimate`, 체력·쿨다운을 사용한다.
- 처치 보상용 런타임 큐는 `W3Party` 내부에서만 관리한다. 저장 데이터와 전투 밸런스는 바꾸지 않는다.
- 보스가 있을 때만 `BossBattle` 상태를 읽어 상단 보스 바를 보여준다.

## 검증 기준

1. 기존 긴 전투 로그 패널이 제거되고 상단 HUD는 72px 이하다.
2. 파티 카드와 스킬 버튼은 하단 148px 안전 영역 안에만 존재한다.
3. 보상 큐는 3개를 넘지 않고 2.2초 후 삭제된다.
4. 1280×720과 1440px 폭에서 상단/우측/하단 UI가 서로 겹치지 않는다.
5. 전투·보스·VFX 테스트 빌드가 컴파일되고 캡처로 UI와 전장이 분리된다.
