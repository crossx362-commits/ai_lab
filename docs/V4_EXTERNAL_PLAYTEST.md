## 공통 준비 (진행자)

1. 빌드를 테스터 PC에 두고, 오너 Unity 세션과 섞지 않는다.
2. 테스터마다 **배정표 한 장**(`docs/feedback/playtest_sheet.md`)을 연다.
3. 시작 전 설명은 최소만: 이동 WASD, 전투는 자동, 하단 1~5가 캐릭터.
4. **이동기(스페이스 대시)는 V2 첫 판이 끝난 뒤에만** 설명한다.
5. 실패 사유는 이 다섯만 쓴다. 섞지 마라.  
   `조작 불명확` / `난이도` / `손실 분노` / `다시 키우기 지루함` / `기술 문제`

## V2 — 손맛 (5명, 테스터 t01~t05)

질문: 대시 무적 0.3초로 **"방금 피했다"**가 나오는가.

| 단계 | 무엇을 | 시간 | 기록 |
|---|---|---|---|
| V2-1 | 필드 사냥. **대시 설명 없이** 한 판 | 10분 | "피했다"고 말한 횟수, 시각 |
| V2-2 | 스페이스=무적 0.3초라고 **짧게 알려준 뒤** 같은 필드 | 10분 | 같은 횟수 |
| V2-3 | 한 문장: 손맛이 있었는가 | — | 예/아니오 + 한 줄 |

통과: **4명 이상**이 한 판에서 "피했다"를 **3회 이상** 정확히 지목.  
증거: 입력/회피 전후 화면 또는 진행자 메모. 설문 한 문장.

조작: 필드 탭 → 출전. 맞을 것 같을 때 스페이스(2판만).

## V3 — 보스 지휘 (5명, 테스터 t01~t05)

질문: 캐릭터 선택 → 위치 + 스킬이 **재미있는가**.

기믹 3종: **동시 장판 / 쫄 소환 / 힐 체크**.

| 단계 | 무엇을 | 기록 |
|---|---|---|
| V3-1 | 같은 파티·같은 5층 보스. **자동 3판** | 클리어 시간, 전멸 여부, 막힌 기믹 |
| V3-2 | 같은 시드. **수동 3판** (1~5 선택, 우클릭 이동, 초상 옆 스킬) | 클리어 시간, 대응한 기믹(장판/소환/힐) |
| V3-3 | 한 문장: 지휘가 답답했는가 | 예/아니오 + 한 줄 |

통과: **4명 이상**이 기믹 3종 중 **2종 이상** 수동 대응. 개인 중앙값으로 수동이 자동보다 **30% 이상 빠름**.  
증거: 시드, 시간 CSV, 실패 기믹, 스크린샷.

조작: 탑 → 5층 보스. 자동 판은 손 떼기. 수동 판만 지휘.

## V4 — 삭제 수용 (10명 전원)

질문: **키운 캐릭터를 잃어도 다시 하고 싶은가.**

| 단계 | 무엇을 | 시간 | 기록 |
|---|---|---|---|
| V4-1 | 배정된 애착 캐릭터 **이름을 확인하고** 장비를 만진다 | 포함 | 이름·직업·장착 |
| V4-2 | 필드·탑·영지(대장간)로 **직접 키운다** | **30분 이상** | 시작/종료 시각, 레벨 |
| V4-3 | 그 캐릭터가 **3회 사망 → 삭제**될 때까지 민다. 저장을 속여 지우지 마라 | 가변 | 삭제 시각, 남은 파티 |
| V4-4 | 직후: 다음 캐릭터를 영입/환생/남은 파티로 **지금 계속하는가** | 즉시 | 예/아니오, 사유 코드 |
| V4-5 | **24시간 뒤** 다시 실행하는가 | +24h | 예/아니오, 사유 코드 |

통과: **7명 이상** 즉시 계속 **그리고** **7명 이상** 24시간 뒤 재실행.  
증거: 삭제 전후 선택, 즉시 계속, 24h 재실행, 이탈 사유.
