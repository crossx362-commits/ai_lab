# GeoGuard

선택한 국가의 IP와의 통신(인바운드/아웃바운드)을 Windows 방화벽 커널 레벨에서 차단하고,
차단 시도를 실시간 알림으로 띄워주는 트레이 상주 프로그램. (구 ChinaGuard)

## 동작 방식

1. **차단** — 트레이 메뉴 "차단 국가 설정..."에서 고른 국가들의 CIDR 목록
   (RIR 위임 데이터 기반, ipverse/rir-ip)을 받아 Windows 방화벽에
   국가별 인바운드+아웃바운드 차단 규칙으로 등록. 커널(WFP)이 차단하므로
   프로그램이 꺼져 있어도 차단은 유지됨. 기본값: 중국(CN).
2. **감지/알림** — WFP 차단 감사 이벤트(보안 로그 5157)를 구독해
   차단 대상국 IP 관련 차단 발생 시 어떤 프로세스가 어디로 접속하려 했는지 풍선 알림.
   같은 (프로세스, IP) 조합은 5분에 1회만 알림 (`Throttler.cs`).
3. **모니터** — 트레이 아이콘 더블클릭 → 현재 TCP 연결 목록 + 국가/조직(ISP) 표시,
   필터/정렬, IP 상세 정보(역방향 DNS 포함), 프로세스 강제 종료.
   차단 대상국 연결은 빨간색 강조.
4. **이력** — 트레이 메뉴 "차단 이력 보기" → 시작 이후 차단된 시도 목록.
5. **적용 실패 시(fail-closed)** — 어떤 국가의 IP 목록을 받지 못해 실제로 차단되지 않으면,
   트레이 아이콘이 경고 아이콘으로 바뀌고 상태에 "OO 미차단 (재시도 중)"이 고정 표시된다.
   동시에 30초부터 최대 30분까지 지수 백오프로 자동 재시도하며, 성공하면 즉시 차단이 켜지고
   아이콘도 정상으로 돌아온다. 사용자에게 모달로 묻지 않는다(경고 피로 회피).
   업스트림에 그 국가의 목록 자체가 없으면(HTTP 404) 재시도를 멈추고 제외를 안내한다.

GeoIP/ASN 데이터: DB-IP Lite (CC BY 4.0, download.db-ip.com)

## 빌드

SDK 불필요. Windows 내장 csc(.NET Framework 4.8)로 빌드:

```
build.cmd
```

## 실행

`GeoGuard.exe` 실행 (관리자 권한 필요, UAC 승인).
첫 실행 시 자동으로 국가별 CIDR 목록/GeoIP DB/ASN DB를 내려받고
방화벽 규칙 등록 + WFP 차단 감사 정책을 활성화한다.
구버전(ChinaGuard) 이름의 방화벽 규칙은 시작 시 자동 정리된다.

## 제거

트레이 메뉴 → "차단 규칙 모두 제거" 후 종료.
감사 정책 원복은 필요 시:

```
auditpol /set /subcategory:"{0CCE9226-69AE-11D9-BED3-505054503030}" /failure:disable
```

## 파일

- `blocked-countries.txt` — 차단 국가 코드 목록 (한 줄에 하나)
- `iplist-{cc}-v4.txt` / `iplist-{cc}-v6.txt` — 국가별 CIDR 캐시
- `dbip-country-lite.csv` / `dbip-asn-lite.csv` — GeoIP/ASN DB 캐시
- `geoguard.log` — 이벤트/차단 로그
